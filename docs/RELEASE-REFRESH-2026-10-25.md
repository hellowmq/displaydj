# Full 1.0.2 / Lite 0.1.0 原位更新

2026-10-25，维护者明确要求覆盖现有 Release/tag。本次保留 Full `v1.0.2`、Lite `lite-v0.1.0` 和资产文件名，标签改指新的固定源码提交，并替换两款产品的 ZIP、DMG 与 SHA-256 文件。Full 保持 latest stable，Lite 保持 prerelease。

相同版本号下的旧下载不包含此次改动。请重新下载，并使用本次同名 `.sha256` 文件校验。源码分支按正常快进交付；本次例外仅替换这两个已授权的标签和对应附件。

## 用户可见变化

- **Lite 基础亮度**：内建屏原生背光、支持的外屏 DDC 硬件亮度；等宽数值、原生滑块、键盘调节、逐屏确认/失败/重试，不静默切换到 Gamma。
- **Full 主面板**：交付已选布局，保留滚轮目标、区分键盘目标，逐屏反馈请求和实际确认，设置分组，明确断开确认及 GUI 恢复后退出。
- **共同反馈**：原生刷新图标按下即有局部反馈，稳定轴心、短促单次旋转、单色；稍久读取才显示“刷新中”，不会延长实际请求。亮度调节不触发刷新动画。Lite 退出文字保持稳定，退出保护仍生效。
- **减少动态效果**：移除刷新装饰运动，仍保留请求语义与真实结果；macOS 13/14 使用静态兼容路径。

## 验证与边界

| 层次 | 已有证据 | 限制 |
| --- | --- | --- |
| 自动测试 | 756 项通过：XCTest 187，Swift Testing 569；涵盖共享刷新 7、Lite 50、DDC Core 200、兼容 CLI 9、Full 303 | 注入后端与隔离存储不证明硬件兼容 |
| CLI / HTTP | 隔离 smoke 检查版本、只读发现、参数拒绝、鉴权、启动与清理 | 不请求硬件写入，不修改日常服务 |
| 原生交互 | Full/Lite 刷新、键盘、慢读取、收尾；Lite 退出文字 33 帧像素一致 | 不是精确输入延迟或全套 VoiceOver 测量 |
| 减少动态效果 | 系统真实切换后，两版各 10 帧刷新图标静止，测试后恢复原设置 | macOS 13/14 为编译兼容路径，尚无最低系统实体测试 |
| Lite 内建屏 | 2026-10-20 在 Apple M1 通过 GUI 调低、独立 DisplayServices 回读及精确原始浮点值恢复，退出后再次读回相同 | 不扩展为外屏 DDC、色彩或物理亮度测量结论 |
| 连接恢复 | 历史 Dell 普通重连、恢复退出、主界面异常结束后恢复通过，用户确认画面正常 | 见 [设备记录](LITE-DEVICE-VERIFICATION.md)，不重复或推广为所有设备保证 |
| 本机安装 | 两产品真实模式、应用身份、运行路径、文件一致性和严格签名已核对 | 不是干净用户首装或所有升级路径测试 |

发布包从固定源码提交构建，两产品分别用同一个 Release App 生成 ZIP 与 DMG；逐文件比较归档内容，挂载只读 DMG，检查产品身份、版本、架构、可执行权限、许可证、签名和 SHA-256。最终公开下载另行回读校验，交付结果见对应 Release 及提交 Checks。

发行范围仍为 **Apple Silicon arm64、macOS 13 部署目标、ad-hoc 签名、未经 Apple 公证**。Intel DDC、干净首装、最低系统、完整睡眠唤醒和更广设备矩阵未完成。不要将部署目标写成最低系统实测。

## 安装与恢复

更新前恢复当前外屏并正常退出对应 App，再替换同名应用。Lite 使用 `DisplayDJLite.app`，Full 使用 `DisplayDJ.app`，恢复记录分别保存在 App 外，不因覆盖安装清理。使用 Full CLI 或可选服务的用户，也应同步更新复制到 PATH 的 CLI，并正常停止旧服务后使用新包启动。

ad-hoc 签名变化可能使 Full 全局快捷键的旧授权失效；按 [Full 发布说明](RELEASE-NOTES-1.0.2.md)重新登记准确的应用路径。连接异常及卸载步骤见 [恢复说明](LITE-RECOVERY.md)。
