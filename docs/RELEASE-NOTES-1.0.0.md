# DisplayDJ 1.0.0

DisplayDJ 1.0.0 是首个面向日常使用收口的版本，提供菜单栏 App、可独立运行的 `display-cli`，以及按需启动的本地 HTTP 服务。

## 主要变化

- 菜单栏与设置窗口支持内建屏亮度、Apple Silicon 外屏 DDC 亮度、逐屏 Gamma 软件调光、对比度、音量、显示模式和命名亮度预设。
- 快捷键可按“已选中的显示器”或“鼠标所在显示器”动态选择目标；首次启用会引导辅助功能授权，并在返回 App 后重新检查权限。
- 可选择让多台显示器按相同百分点同步调整硬件亮度；默认关闭，单屏失败会单独报告。
- 显示模式切换加入确认与恢复守护，显示器断开／重连记录使用稳定身份并在拓扑变化后重新枚举。
- CLI 与 daemon 增加版本不匹配提示，软件调光接口、恢复状态和错误契约得到补强。
- 新增 arm64 ZIP／DMG 打包、SHA-256 sidecar 和离线包一致性校验。

## 下载与安全提示

本次提供的 ZIP 和 DMG 仅包含 **Apple Silicon arm64** 构建。App 使用 ad-hoc 签名，**没有 Developer ID 签名，也没有 Apple 公证**。因此首次打开时 macOS 可能阻止启动；可在 Finder 中按住 Control 点击 DisplayDJ 后选择“打开”，或在“系统设置 → 隐私与安全性”中确认打开。

全局快捷键需要“辅助功能”权限。授权后若快捷键未立即生效，请退出并重新打开 DisplayDJ。重新下载、替换或重建 ad-hoc 签名的 App 后，macOS 可能要求再次授权。

## 已知边界

- 最低部署目标是 macOS 13，但本次实际安装与硬件验收在 Apple Silicon、macOS 27 完成；没有 Intel 构建和最低系统版本实测。
- DDC 支持取决于显示器、输入口、线材和转接链路。HP D27k 当前连接验证了亮度与对比度写入、独立回读和恢复；该结果不代表同品牌或其他连接均可用。
- Gamma 是显式的软件调光，需要进程保持效果，不等同于硬件背光；DisplayDJ 不会在 DDC 失败后静默改用 Gamma。
- 断开／重连和显示模式依赖 macOS 私有或设备相关行为，不承诺所有硬件均支持。
- 尚未提供原生亮度媒体键、系统 OSD、连续硬件与软件混合曲线、HDR/XDR 增强、虚拟屏或 EDID 覆写。

完整证据与限制见 [验证记录](VALIDATION.md)、[设备验证](DEVICE-VALIDATION.md)和 [1.0 验收清单](RELEASE-1.0-CHECKLIST.md)。
