# DisplayDJ Full 1.2.0 / Lite 0.3.0

Full 1.2.0 是稳定版；Lite 0.3.0 仍为预发布。两款应用首次提供内置更新。此前的 Full 1.1.0 / Lite 0.2.0 没有更新器，需要从对应的 GitHub Release 手动下载这次更新。

- [Full 1.2.0 下载](https://github.com/hellowmq/displaydj/releases/tag/v1.2.0)：在主面板菜单或「设置 → 操作偏好」检查更新。
- [Lite 0.3.0 预发布下载](https://github.com/hellowmq/displaydj/releases/tag/lite-v0.3.0)：在「亮度与连接操作说明」检查更新，不需要 Full、CLI 或后台服务。

更新器区分两个产品的标签和安装包，校验 SHA-256、应用标识、版本和代码签名。先暂存新版，再按原有恢复流程退出并替换应用；取消退出会保留原应用并清理暂存包。交换失败或 macOS 拒绝启动新版时尝试回滚；成功交换会保留旧版备份。两版也改进了菜单弹窗动画和亮度读数布局；Full 不再截获内建屏的系统媒体亮度键。

## 验证范围

- 完整自动测试 782 项（XCTest 187、Swift Testing 595），以及 Full CLI／隔离 HTTP 服务和 Lite 包身份检查。
- 两个原生候选窗口打开各自的更新入口，并对官方 GitHub 源执行检查。Lite 在模拟外屏上核对取消、断开、重新连接；未触碰实际屏幕亮度或连接。
- 使用同一更新器、真实 AppKit 退出通知、回环 HTTP 和严格签名校验，对两种产品分别演练替换并重启、取消并清理、拒绝错误校验和、拒绝启动新版后恢复旧版。演练在临时目录的签名测试 App 中完成，没有覆盖 `/Applications`；不等于正常安装目录或所有机器的升级验收。
- ZIP 和 DMG 由同一产品的同一 App 生成，分别检查内容、架构、版本、签名和 SHA-256。未重做外屏硬件矩阵、最低系统安装或 Gatekeeper 首次启动验收。

## 安装与恢复

安装包是 Apple Silicon arm64、ad-hoc 签名、未经过 Apple 公证；macOS 13 是部署目标。更新前先恢复外屏并退出旧版，再替换对应 App，保留应用外的设置与恢复记录。Full 如将 CLI 复制到了 PATH，需同步更新；辅助功能权限也可能需要系统重新确认。遇到回归，可按同样顺序安装旧版 [Full 1.1.0](https://github.com/hellowmq/displaydj/releases/tag/v1.1.0) 或 [Lite 0.2.0](https://github.com/hellowmq/displaydj/releases/tag/lite-v0.2.0)，不要删除恢复记录来绕过失败。

## English

Full 1.2.0 is stable; Lite 0.3.0 remains a prerelease. This is the first version with an in-app updater, so users of earlier releases must download and replace the corresponding app manually. Full checks in its menu or Operation Preferences; Lite checks in its brightness and connection help panel. The updater verifies the archive checksum, app identifier, version and signature, stages the replacement before quit, and attempts to restore the previous app if the swap or Launch Services relaunch fails. Cancelled quits keep the original app in place.

Distribution is arm64, ad-hoc signed and not notarized, with a macOS 13 deployment target. Update replacement and recovery were exercised with signed fixtures in isolated directories. A clean installation on the minimum OS and further physical display checks were outside this release validation.
