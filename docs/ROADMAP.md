# 后续里程碑

详细实现范围、工作量估算与验收条件见 [COMPETITIVE-PLAN.md](COMPETITIVE-PLAN.md)。

v0.3.0 预览版已补齐：DDC 对比度/音量、系统已有显示模式、命名亮度预设、对应 CLI/API/菜单栏窗口，以及参数与失败契约。2026-09-22 工作区代码在 HP D27k 当前连接上完成亮度与对比度的物理写入、回读及恢复；该屏音量 VCP 明确不支持。Dell 当前连接仍无 DDC 基线。两台设备的结果不能互相推广，详见 [DEVICE-VALIDATION.md](DEVICE-VALIDATION.md)。

下一阶段按依赖顺序推进：

1. **真实硬件验收**：HP 当前链路的亮度和对比度已通过基线、小幅变化、独立回读、恢复；继续扩展 GUI、连接与睡眠唤醒矩阵。
2. **手动亮度优先**：1.0.1 源码已加入逐屏控制版本、恢复点所有权和跨进程协调；手动接管会暂停已有会话对该屏的调光及恢复，daemon 仍可选。实现与验收见 [MANUAL-BRIGHTNESS-PRIORITY.md](MANUAL-BRIGHTNESS-PRIORITY.md)。独立的暂停／恢复按钮、其他显示控制项仲裁留后续需求。
3. **显式软件调光与桌面体验**：Gamma 设置和恢复、多屏快捷键目标与可选相同百分点硬件亮度同步已在工作区实现，仍需真实 GUI 操作验收；混合调光、媒体键、OSD 后续单独推进。不能把软件变暗标成背光，也不能在 DDC 失败后隐式改变 GUI 控制方式。
4. **桌面与协议扩展**：布局/主屏/镜像/旋转、复合预设、能力字符串、输入源和静音等离散 VCP、Intel 后端。
5. **CLI 自动化扩展**：机器 schema、shell completion、事件 watch、幂等请求与事件预设；保持 GUI 可选。
6. **高级显示专项**：虚拟屏、灵活 HiDPI、HDR/XDR、颜色与视频能力，按 macOS/芯片/设备单独验证。
7. **可靠分发**：双架构 CI、签名、公证、安装升级与回滚；本地构建不能作为正式发布证据。
