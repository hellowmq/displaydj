# 后续里程碑

完整的竞品差距、优先级、实现范围、工作量估算与验收条件见 [COMPETITIVE-PLAN.md](COMPETITIVE-PLAN.md)。

v0.3.0 预览版已补齐：DDC 对比度/音量、系统已有显示模式、命名亮度预设、对应 CLI/API/菜单栏窗口，以及参数与失败契约。新功能仍未完成物理写入验收。

下一阶段按依赖顺序推进：

1. **真实硬件验收**：一条成功 DDC 链路，先读取基线，小幅变化、独立回读、恢复；随后扩展连接与睡眠唤醒矩阵。
2. **单一控制服务与所有权**：基础亮度卡片也走服务，用户意图优先，可暂停 Agent；快照绑定 transport 和所有者，状态事务串行化。
3. **显式软件调光与桌面体验**：Gamma 设置和恢复、混合调光、媒体键、OSD、多屏同步；不能把软件变暗标成背光，也不能在 DDC 失败后隐式改变 GUI 控制方式。
4. **桌面与协议扩展**：布局/主屏/镜像/旋转、复合预设、能力字符串、输入源和静音等离散 VCP、Intel 后端。
5. **CLI 自动化扩展**：机器 schema、shell completion、事件 watch、幂等请求与事件预设；保持 GUI 可选。
6. **高级显示专项**：虚拟屏、灵活 HiDPI、HDR/XDR、颜色与视频能力，按 macOS/芯片/设备单独验证。
7. **可靠分发**：双架构 CI、签名、公证、安装升级与回滚；本地构建不能作为正式发布证据。
