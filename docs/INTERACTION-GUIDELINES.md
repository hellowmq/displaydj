# DisplayDJ 交互取舍

2026-10-02。参考用户提供的 `ui-component/docs/interaction-master-lessons.md`，采用其中的工程经验；未复制 HTML 展示源码。

## 本次采用

- **直接调节跟手**：拖动亮度条时，填充与滑块位置直接反映同一个拖动值，移除拖动中的弹簧延迟与超调。非拖动的离散变化使用同一个短缓动。
- **减少动态效果**：遵循 macOS 的“减少动态效果”，关闭亮度条过渡、数字滚动、排序编辑过渡和回读值过渡；数值及操作结果仍立即可读。
- **生命周期清理**：亮度条消失或失去控制能力时清除拖动状态。拖动期间已经提交的最新亮度意图继续由现有队列处理，不增加一次额外硬件写入。

对应经验卡 08、09、12 及共同工程边界。已有的逐屏意图合并、键盘/VoiceOver 控制、未知读数状态和真实回读保持原有规则。

## 暂不采用

粒子、逐字揭示、故障闪光、音效、分镜时间轴适合展示或教程，当前显示控制操作没有相应需求。持续动画会增加干扰和驻留成本；不能由参考样本推断本机性能或硬件调节效果。

本次属于局部呈现与生命周期改进，未做交互性能测量或真实指针操作验收。构建和自动回归的结果由本轮交付记录说明。
