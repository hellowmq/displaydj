# 键盘调光与屏幕提示

2026-10-12 更新；1.0.2 已发布。

## 行为与范围

- 独立的「亮度媒体键」开关，默认关闭；现有固定快捷键保持独立。用户启用时才请求辅助功能权限，启动不弹授权提示。
- 接管无修饰键的亮度媒体事件及系统亮度键码 144/145。普通 F1/F2、F14/F15、音量、播放和带 Command/Control/Option/Shift 的按键不接管。
- 目标沿用「选中的显示器／鼠标所在显示器」。媒体键一次长按固定目标身份，抬键不重复写入；目标不可解析时交给系统，不回退到另一块屏幕。
- 冷启动或关闭菜单后首次调节先读取硬件亮度；连续按键串行合并，逐步限幅，避免长按堆积硬件写入。同步选项仍适用。
- 固定快捷键和媒体键共用调节流程。每块实际调整的显示器显示短暂提示：首次无数值时提示读取，连续调节保持数值和文案稳定，回读结果与失败明确反馈；浮层不抢焦点、不拦鼠标，遵循系统外观。
- 写入复用现有手动亮度控制权；DDC 失败不自动使用 Gamma。权限撤销、关闭开关和退出时停止监听。

## 验收

1. 按下、长按和抬起只产生预期调节；不干扰音量、播放、普通功能键与系统修饰键组合。
2. 长按时移动鼠标、切换选中屏或插拔设备，不改变已捕获的目标。
3. 冷读期间与慢写期间的连续增减不丢失，边界反向调节正确；错误提示不冒充成功回读。
4. 同步调节逐屏呈现结果；旧 Agent 不能覆盖键盘操作的新意图。
5. 自动测试、Swift 构建、CLI smoke 和 App 打包检查通过；实际键盘、权限、浮层与外屏证据分别记录。

## 使用方式

在菜单栏或「显示设置与预设」的亮度快捷键区域开启「亮度媒体键」，按提示授予辅助功能权限。多屏时选择「按键目标」。按键每次增减 5 个百分点，长按继续调节，抬起停止；选中同步调节时，其他可控制屏按相同百分点变化。

提示浮层在实际目标屏出现，调节中显示目标值，完成后显示硬件回读值；失败时显示原因。原有 `⌃⌘- / ⌃⌘=` 快捷键也使用同样的浮层。固定快捷键使用主动事件拦截，已接管的按下、重复和抬起不会继续传给前台应用，避免前台应用对无效按键发出提示音；普通快捷键照常透传。当前提示没有动画，系统「减少动态效果」下不会增加过渡。

本功能使用键盘发出的亮度动作。如果键盘将顶排设为普通 F1/F2，需按键盘／macOS 对应方式发出亮度动作；不会把普通 F1/F2 或音量、播放键改成调光键。其他调光软件也可能接管这些按键，同时运行的冲突未验证。

已有 1.0.1 下载包不含本功能。1.0.2 已发布，下载与升级授权方式见 [发布说明](RELEASE-NOTES-1.0.2.md)。下文保留开发期间的分阶段验证记录，历史“未发布”状态不代表当前发布状态。
